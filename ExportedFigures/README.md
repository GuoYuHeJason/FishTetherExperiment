# README
TS_compensation_figures: This folder contains the figures generated from the analysis of compensated TS values for all fish in the experiment. Each figure represents the distribution and trends of compensated TS values across different frequencies, allowing for a visual comparison of their acoustic properties. The figures are organized by fish ID and can be used to identify patterns or anomalies in the data.

also the 3 figures combine all individuals within each species (LT, LWF, SMB) into a single plot for easier comparison.
